แต่ละยุคแก้ปัญหาของยุคก่อนหน้า — Next.js แก้ปัญหาเรื่อง SEO, Routing และ Backend ที่ React เพียงอย่างเดียวทำได้ยาก

⚖️ React (CRA) vs Next.js

คุณสมบัติReact (CRA/Vite)Next.js
Routingต้องติดตั้งเพิ่มเองFile-based Routing ในตัว
RenderingCSR เท่านั้นSSR / SSG / ISR / CSR
Backendแยกโปรเจกต์ต่างหากมี API Routes ในตัว
SEOทำได้ยากทำได้ดี

🗂️ โครงสร้าง App Router

ไฟล์สำคัญ

  • app/layout.js โครงสร้างหลักร่วมทุกหน้า
  • app/page.js เนื้อหาของแต่ละเส้นทาง
  • app/globals.css สไตล์ส่วนกลาง

Server vs Client Component

  • Server Component (ค่าเริ่มต้น) — เบา เร็ว ดึงข้อมูลตรง
  • Client Component — ต้องมี "use client" เมื่อใช้ useState/คลิก

🛠️ Live Demo: 4 ขั้นตอนสู่โปรเจกต์แรก

1) node -v  &&  npm -v
2) npx create-next-app@latest first-nextjs-app
3) cd first-nextjs-app  &&  npm run dev
4) git init  &&  git add .  &&  git commit -m "Initial commit"
   git remote add origin https://github.com/ชื่อผู้ใช้/first-nextjs-app.git
   git push -u origin main
